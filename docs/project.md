# О проекте NetWatch

## Название проекта

**NetWatch — система мониторинга сетевых ресурсов.**

## Цель

Разработать программный прототип, который позволяет проверять доступность сетевых узлов и TCP-портов, а также сохранять результаты проверок для последующего анализа.

## Актуальность

Современная информационная инфраструктура зависит от доступности серверов, сетевых устройств и сервисов. Даже кратковременная недоступность узла может привести к остановке работы пользователей, потере доступа к веб-ресурсам или невозможности подключиться к корпоративным сервисам.

Мониторинг помогает своевременно обнаруживать проблемы в сети, контролировать состояние серверов и фиксировать историю проверок. Проект NetWatch демонстрирует базовые принципы работы систем наблюдения за сетевой инфраструктурой на практике, доступной для реализации в рамках учебного курса.

## Задачи

- Изучить основы сетевого мониторинга и протоколов ICMP и TCP.
- Рассмотреть принципы диагностики доступности сетевых узлов.
- Реализовать проверку доступности IP-адресов и доменных имён с помощью ping.
- Реализовать проверку заданных TCP-портов средствами Python.
- Организовать сохранение результатов проверок в журнал в формате CSV.
- Подготовить техническую документацию проекта.
- Создать статический веб-сайт, представляющий проект.
- Провести тестирование программы на нескольких публичных сетевых ресурсах.

## Целевая аудитория

- Начинающие системные администраторы.
- Студенты направлений информационной безопасности и информационных технологий.
- Пользователи, изучающие основы компьютерных сетей.
- Разработчики, желающие изучить принципы построения простых систем мониторинга.

## Используемые технологии

- Python 3 — основной язык реализации.
- Модуль `socket` — проверка доступности TCP-портов.
- Модуль `subprocess` — вызов системной утилиты ping.
- Формат CSV — хранение журнала проверок.
- HTML и CSS — статический сайт проекта.
- Git и GitVerse — контроль версий и совместная работа.

## Ожидаемый результат

Результатом работы является работающий прототип программы NetWatch, исходный код с комментариями, техническая документация, журнал тестирования и статический веб-сайт с полным описанием проекта.
