# Журнал прогресса проекта

## Запись 1 — Планирование проекта

- Изучено задание на проектную (учебную) практику.
- Выбрана тема проекта: NetWatch — система мониторинга сетевых ресурсов.
- Определены цель, задачи и ожидаемые результаты проекта.
- Сформирована предварительная структура Git-репозитория.
- Настроена локальная среда Git, создан SSH-ключ для работы с GitVerse.

## Запись 2 — Документация и подготовка сайта

- Созданы основные Markdown-документы проекта: описание проекта, участники, ресурсы.
- Разработана структура статического сайта: главная страница, «О проекте», «Участники», «Журнал», «Ресурсы».
- Подготовлена визуальная схема архитектуры программы NetWatch.
- Проведена вёрстка сайта на HTML и CSS, сайт проверен локально в браузере.

## Запись 3 — Разработка прототипа и тестирование

- Реализована проверка доступности сетевых хостов через системную утилиту ping.
- Добавлена проверка состояния TCP-портов средствами модуля socket.
- Настроено сохранение результатов проверок в CSV-журнал.
- Проведено тестирование программы на нескольких публичных сетевых узлах (DNS-серверы, веб-серверы).
- Составлен туториал по созданию системы мониторинга с нуля.

## Запись 4 — Итоговое оформление

- Подготовлен отчёт по изучению больших языковых моделей (LLM).
- Оформлен отчёт о взаимодействии с организацией-партнёром и участии в Карьерном марафоне.
- Доработана документация проекта, обновлён сайт.
- Составлен итоговый отчёт по практике в формате DOCX и PDF.
