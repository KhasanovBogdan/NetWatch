# Полезные ресурсы

## Документация и обучение

- [Документация Git](https://git-scm.com/book/ru/v2) — руководство по системе контроля версий Git.
- [Документация GitVerse](https://gitverse.ru/docs/) — справочные материалы по работе с платформой GitVerse.
- [Работа с SSH-ключами в GitVerse](https://gitverse.ru/docs/collaborative/authentification/ssh-keys/) — настройка безопасного доступа к репозиторию.
- [Введение в Git (Skillbox)](https://skillbox.ru/media/code/chto_takoe_git_obyasnyaem_na_skhemakh/) — понятное объяснение основ Git.
- [Курс Hexlet по Git](https://ru.hexlet.io/courses/intro_to_git) — практический курс по системе контроля версий.
- [Уроки по Markdown (Hexlet)](https://ru.hexlet.io/lesson_filters/markdown) — синтаксис и практика Markdown.

## Веб-технологии

- [Основы HTML (MDN)](https://developer.mozilla.org/ru/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content) — учебные материалы по HTML.
- [Основы CSS (MDN)](https://developer.mozilla.org/ru/docs/Web/CSS) — справочник по CSS.
- [Дока (справочник)](https://doka.guide/) — русскоязычный справочник по веб-разработке.

## Материалы по сетям

- [Документация модуля socket](https://docs.python.org/3/library/socket.html) — работа с сетевыми соединениями в Python.
- [Документация модуля subprocess](https://docs.python.org/3/library/subprocess.html) — запуск системных команд из Python.

## Искусственный интеллект

- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) — курс по большим языковым моделям и обработке естественного языка.
- [Hugging Face NLP Course](https://huggingface.co/learn/nlp-course) — курс по обработке естественного языка.
