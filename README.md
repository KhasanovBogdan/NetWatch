# NetWatch — система мониторинга сетевых ресурсов

Учебный проект, выполненный в рамках проектной (учебной) практики.

## Цель проекта

Разработать прототип системы мониторинга доступности сетевых узлов и TCP-портов с сохранением результатов проверок в журнал.

## Возможности

- Проверка доступности узлов с помощью ping (ICMP).
- Проверка открытости TCP-портов.
- Измерение статуса ответа для каждой проверки.
- Сохранение результатов в CSV-журнал.
- Формирование понятного отчёта о состоянии проверяемых ресурсов.

## Структура репозитория

- `docs/` — документация проекта и отчёты.
- `site/` — статический веб-сайт проекта.
- `src/` — исходный код программы.
- `reports/` — итоговый отчёт по практике.
- `task/` — задание и шаблоны.

## Запуск

```bash
cd src
python main.py
```
