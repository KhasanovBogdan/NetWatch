# Исходный код NetWatch

Файл `main.py` содержит полную реализацию прототипа системы мониторинга сетевых ресурсов.

## Запуск

```bash
python main.py
```

После запуска в этой же папке появится файл `monitoring_log.csv` с результатами проверок.

## Требования

Python 3.10 или новее. Внешние зависимости не требуются — используется только стандартная библиотека.
