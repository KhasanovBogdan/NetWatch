NetWatch — система мониторинга сетевых ресурсов

Учебный проект в рамках проектной (учебной) практики. Программа проверяет доступность сетевых узлов и TCP-портов, сохраняет результаты в журнал и демонстрирует базовые принципы построения систем мониторинга сетевой инфраструктуры.

Аннотация проекта

Современная инфраструктура зависит от постоянной доступности серверов и сетевых сервисов. NetWatch — это прототип, показывающий, как можно проверять состояние узлов с помощью ping и TCP-соединений, а затем сохранять историю проверок для дальнейшего анализа.

Проверка доступности

Проверка узлов по ICMP (ping) с определением статуса ответа.

Проверка портов

Проверка TCP-портов через модуль socket с диагностикой ошибок.

Журнал результатов

Сохранение истории проверок в CSV-файл для последующего анализа.

Ключевая информация

  • Язык реализации: Python 3.
  • Формат хранения результатов: CSV.
  • Тип практики: проектная (учебная), 72 академических часа.
  • Вариативная часть: реализация технологии «с нуля».
